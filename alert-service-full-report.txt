# Alert Service — Phase 6

This module is added against the actual uploaded `log-platform` source tree (Spring Boot 3.3.4, Java 21, MySQL 8.4, Redis 7.2). It consumes the existing `com.logplatform.common.ProcessedLogEvent` contract from `common-core` and the `logs.processed` stream. It writes only to `alert_db`; it does not modify `logs_db`.

## Implemented
- Tenant-scoped alert-rule CRUD (severity/service/environment matchers, threshold and time window).
- Redis sorted-set sliding-window counter (Lua script keeps prune/add/count atomic).
- Threshold evaluation and deterministic rule/event-dimension fingerprint.
- Incident creation, duplicate active-incident occurrence updates, acknowledge/assign/resolve endpoints.
- MySQL notification outbox and retrying publisher to `notifications.out`.
- Redis consumer group creation, event ACK after DB transaction, malformed/permanent-event DLQ.
- Flyway schema, Dockerfile, Compose profile, actuator health endpoints.

## Important engineering notes / limitations
1. This package matches the uploaded code's `ProcessedLogEvent` record exactly: `eventId`, numeric `tenantId`, `timestamp`, `service`, `environment`, `severity`, `message`, `traceId`, `fingerprint`.
2. Gateway must route `/api/v1/alert-rules/**` and `/api/v1/incidents/**` to `http://alert-service:8086` (or `http://localhost:8086` when running on host). Add those routes to `api-gateway/src/main/resources/application.yml`. The existing Gateway strips spoofed tenant headers and re-adds verified JWT claims. The Alert Service currently treats `X-Tenant-Id` as trusted internal context; do not expose port 8086 publicly in production. For direct host testing, this trust boundary is not secure by itself.
3. `notification-service` is Phase 7 and is not in this package. This service publishes versioned JSON payloads on `notifications.out` with fields `eventKey`, `tenantId`, and `payload`.
4. Consumer ACK occurs after the transactional evaluator returns. The implementation is an initial Phase 6 baseline, not a claim of fully verified production-grade pending-message reclaim/concurrency recovery. The consumer group persists pending entries; a dedicated XPENDING/XAUTOCLAIM recovery worker and robust concurrent active-fingerprint locking should be added before declaring Phase 6 production-complete.
5. Sliding-window counter currently uses a unique member per delivery. To avoid duplicate-delivery inflation in a strict production system, persist/claim event idempotency per tenant/rule or use a deterministic sorted-set member and update it atomically. Do not treat this baseline as exactly-once processing.

## Build and run
From the project root:

```bash
mvn -pl alert-service -am clean test
mvn -pl alert-service -am package -DskipTests
```

Start MySQL and Redis first (`docker compose up -d mysql redis`). Ensure `.env` has `ALERT_DB_PASSWORD` and `REDIS_PASSWORD`, and the MySQL init scripts create `alert_db` plus `alert_svc` with the grants shown in the integration SQL. Then:

```bash
docker compose --profile alerting up -d --build alert-service
# or run on host after dependencies are available:
ALERT_DB_URL='jdbc:mysql://127.0.0.1:3307/alert_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC' ALERT_DB_USERNAME=alert_svc ALERT_DB_PASSWORD='your-local-value' REDIS_HOST=127.0.0.1 REDIS_PASSWORD='your-local-value' mvn -pl alert-service spring-boot:run
```

Health: `GET http://localhost:8086/actuator/health`.

## API
All tenant-scoped endpoints require trusted `X-Tenant-Id` context from the Gateway.

- `POST /api/v1/alert-rules`
- `GET /api/v1/alert-rules`
- `PUT /api/v1/alert-rules/{id}`
- `DELETE /api/v1/alert-rules/{id}` (soft-disable)
- `GET /api/v1/incidents?status=OPEN`
- `GET /api/v1/incidents/{id}`
- `POST /api/v1/incidents/{id}/acknowledge`
- `POST /api/v1/incidents/{id}/assign` body `{"value":"on-call"}`
- `POST /api/v1/incidents/{id}/resolve`

Example rule:

```json
{"name":"Payment API errors","description":"5 errors in 60 seconds","severity":"ERROR","serviceName":"payment-api","environment":"production","thresholdCount":5,"windowSeconds":60,"cooldownSeconds":300,"enabled":true}
```

@Service public class AlertEvaluationService {
 private final RuleRepository rules; private final IncidentRepository incidents; private final NotificationOutboxRepository outbox; private final SlidingWindowCounter counter; private final StringRedisTemplate redis; private final ObjectMapper mapper; private final AlertProperties props;
 public AlertEvaluationService(RuleRepository r,IncidentRepository i,NotificationOutboxRepository o,SlidingWindowCounter c,StringRedisTemplate redis,ObjectMapper m,AlertProperties p){rules=r;incidents=i;outbox=o;counter=c;this.redis=redis;mapper=m;props=p;}
 @Transactional public void evaluate(ProcessedLogEvent e){if(e==null||e.tenantId()<=0||e.eventId()==null||e.timestamp()==null||e.severity()==null)return;
  for(RuleEntity rule:rules.findByTenantIdAndEnabledTrue(e.tenantId())){if(!matches(rule,e))continue;String fp=fingerprint(e,rule);String key=props.windowKeyPrefix()+e.tenantId()+":"+rule.getId()+":"+fp;long count=counter.addAndCount(key,e.eventId(),e.timestamp(),rule.getWindowSeconds());if(count<rule.getThresholdCount())continue;
   Optional<IncidentEntity> active=incidents.findFirstByTenantIdAndFingerprintAndStatusIn(e.tenantId(),fp,List.of("OPEN","ACKNOWLEDGED"));
   if(active.isPresent()){IncidentEntity incident=active.get();incident.touch(e.timestamp());continue;}
   IncidentEntity incident=incidents.save(new IncidentEntity(e.tenantId(),rule.getId(),fp,rule.getName(),"Threshold reached: "+count+" events in "+rule.getWindowSeconds()+" seconds",e.timestamp()));
   String eventKey="incident-created:"+incident.getTenantId()+":"+incident.getId();Map<String,Object> payload=new LinkedHashMap<>();payload.put("eventId",eventKey);payload.put("tenantId",e.tenantId());payload.put("incidentId",incident.getId());payload.put("ruleId",rule.getId());payload.put("title",incident.getTitle());payload.put("status",incident.getStatus());payload.put("occurredAt",e.timestamp().toString());try { outbox.save(new NotificationOutboxEntity(eventKey,e.tenantId(),mapper.writeValueAsString(payload),Instant.now())); } catch (com.fasterxml.jackson.core.JsonProcessingException jsonError) { throw new IllegalStateException("Could not serialize incident notification", jsonError); }
  }
 }
 private boolean matches(RuleEntity r,ProcessedLogEvent e){return (r.getSeverity()==null||r.getSeverity().equalsIgnoreCase(e.severity().name()))&&(r.getServiceName()==null||r.getServiceName().equals(e.service()))&&(r.getEnvironment()==null||r.getEnvironment().equals(e.environment()));}
 private String fingerprint(ProcessedLogEvent e,RuleEntity r){String raw=e.tenantId()+"|"+r.getId()+"|"+Objects.toString(e.service(),"")+"|"+Objects.toString(e.environment(),"")+"|"+e.severity();try{byte[] b=MessageDigest.getInstance("SHA-256").digest(raw.getBytes(StandardCharsets.UTF_8));return HexFormat.of().formatHex(b);}catch(Exception x){throw new IllegalStateException(x);}}
}

package com.logplatform.common;

/**
 * Business exception carrying an HTTP status and a stable machine-readable code. Mapped to JSON by common-web.
 */
public class ApiException extends RuntimeException {
    private final int status;
    private final String code;

    public ApiException(int status, String code, String message) {
        super(message);
        this.status = status;
        this.code = code;
    }

    public int getStatus() {
        return status;
    }

    public String getCode() {
        return code;
    }

    public static ApiException badRequest(String code, String msg) {
        return new ApiException(400, code, msg);
    }

    public static ApiException unauthorized(String msg) {
        return new ApiException(401, "UNAUTHORIZED", msg);
    }

    public static ApiException forbidden(String msg) {
        return new ApiException(403, "FORBIDDEN", msg);
    }

    public static ApiException notFound(String msg) {
        return new ApiException(404, "NOT_FOUND", msg);
    }

    public static ApiException conflict(String code, String msg) {
        return new ApiException(409, code, msg);
    }

    public static ApiException tooManyRequests(String msg) {
        return new ApiException(429, "RATE_LIMITED", msg);
    }

    public static ApiException unavailable(String msg) {
        return new ApiException(503, "UNAVAILABLE", msg);
    }
}

            throw new IllegalStateException(e);
        }
    }

package com.logplatform.common;

import java.util.Locale;
import java.util.Optional;

/**
 * Normalized log severity. {@link #parse(String)} maps common aliases from different logging frameworks.
 */
public enum Severity {
    TRACE, DEBUG, INFO, WARN, ERROR, FATAL;

    public boolean atLeast(Severity other) {
        return this.ordinal() >= other.ordinal();
    }

    public static Optional<Severity> parse(String raw) {
        if (raw == null) return Optional.empty();
        Severity s = switch (raw.trim().toUpperCase(Locale.ROOT)) {
            case "TRACE", "FINEST" -> TRACE;
            case "DEBUG", "FINE" -> DEBUG;
            case "INFO", "INFORMATION", "NOTICE" -> INFO;
            case "WARN", "WARNING" -> WARN;
            case "ERROR", "ERR", "SEVERE" -> ERROR;
            case "FATAL", "CRITICAL", "PANIC" -> FATAL;
            default -> null;
        };
        return Optional.ofNullable(s);
    }
}

package com.logplatform.web;
import com.logplatform.common.Headers;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.util.UUID;
import org.slf4j.MDC;
import org.springframework.web.filter.OncePerRequestFilter;
/** Reads X-Correlation-Id (set by the gateway) or creates one, and exposes it to logs via MDC key "correlationId". */
public class CorrelationIdFilter extends OncePerRequestFilter {
  public static final String MDC_KEY = "correlationId";
  @Override
  protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain) throws ServletException, IOException {
    String id = req.getHeader(Headers.X_CORRELATION_ID);
    if (id == null || id.isBlank()) id = UUID.randomUUID().toString();
    MDC.put(MDC_KEY, id);
    res.setHeader(Headers.X_CORRELATION_ID, id);
    try { chain.doFilter(req, res); } finally { MDC.remove(MDC_KEY); }
  }
}

package com.logplatform.web;
import com.logplatform.common.ApiException;
import jakarta.validation.ConstraintViolationException;
import java.time.Instant;
import java.util.LinkedHashMap;
import java.util.Map;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.slf4j.MDC;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.web.ErrorResponse;
import org.springframework.web.bind.MethodArgumentNotValidException;
import org.springframework.web.bind.ServletRequestBindingException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;
import org.springframework.web.method.annotation.MethodArgumentTypeMismatchException;
@RestControllerAdvice
public class GlobalExceptionHandler {
  private static final Logger log = LoggerFactory.getLogger(GlobalExceptionHandler.class);

  @ExceptionHandler(ApiException.class)
  public ResponseEntity<ApiError> api(ApiException e) { return build(e.getStatus(), e.getCode(), e.getMessage(), null); }

  @ExceptionHandler(MethodArgumentNotValidException.class)
  public ResponseEntity<ApiError> invalid(MethodArgumentNotValidException e) {
    Map<String, String> fields = new LinkedHashMap<>();
    e.getBindingResult().getFieldErrors().forEach(f -> fields.putIfAbsent(f.getField(), f.getDefaultMessage()));
    return build(400, "VALIDATION_FAILED", "Request validation failed", fields);
  }

  @ExceptionHandler(ConstraintViolationException.class)
  public ResponseEntity<ApiError> constraint(ConstraintViolationException e) {
    Map<String, String> fields = new LinkedHashMap<>();
    e.getConstraintViolations().forEach(v -> fields.putIfAbsent(v.getPropertyPath().toString(), v.getMessage()));
    return build(400, "VALIDATION_FAILED", "Request validation failed", fields);
  }

  @ExceptionHandler(HttpMessageNotReadableException.class)
  public ResponseEntity<ApiError> unreadable(HttpMessageNotReadableException e) {
    Throwable cause = e;
    while (cause != null) {
      if (cause instanceof com.fasterxml.jackson.core.JsonProcessingException) {
        return build(400, "MALFORMED_JSON", "Request body contains invalid JSON", null);
      }
      cause = cause.getCause();
    }
    return build(400, "BAD_REQUEST", "Malformed request", null);
  }

  @ExceptionHandler({ServletRequestBindingException.class, MethodArgumentTypeMismatchException.class})
  public ResponseEntity<ApiError> badRequest(Exception e) {
    return build(400, "BAD_REQUEST", "Malformed request", null);
  }

  @ExceptionHandler(Exception.class)
  public ResponseEntity<ApiError> other(Exception e) {
    if (e instanceof ErrorResponse er) { // framework exceptions that already know their status (404, 405, 415 ...)
      HttpStatus s = HttpStatus.valueOf(er.getStatusCode().value());
      return build(s.value(), s.name(), s.getReasonPhrase(), null);
    }
    log.error("Unhandled exception", e);
    return build(500, "INTERNAL_ERROR", "Unexpected error", null);
  }

  private ResponseEntity<ApiError> build(int status, String code, String message, Map<String, String> fields) {
    return ResponseEntity.status(status).body(new ApiError(Instant.now(), status, code, message, MDC.get(CorrelationIdFilter.MDC_KEY), fields));
  }
}

package com.logplatform.web;

import com.fasterxml.jackson.databind.ObjectMapper;
import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;
import java.io.IOException;
import java.time.Instant;
import org.slf4j.MDC;
import org.springframework.web.filter.OncePerRequestFilter;

public class RequestSizeLimitFilter extends OncePerRequestFilter {
    private final long maxBytes;
    private final ObjectMapper objectMapper;

    public RequestSizeLimitFilter(long maxBytes, ObjectMapper objectMapper) {
        this.maxBytes = maxBytes;
        this.objectMapper = objectMapper;
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response,
                                    FilterChain filterChain) throws ServletException, IOException {
        if (request.getContentLengthLong() > maxBytes) {
            response.setStatus(HttpServletResponse.SC_REQUEST_ENTITY_TOO_LARGE);
            response.setContentType("application/json");
            ApiError error = new ApiError(
                Instant.now(), 413, "PAYLOAD_TOO_LARGE",
                "Request body exceeds the configured size limit",
                MDC.get(CorrelationIdFilter.MDC_KEY), null
            );
            objectMapper.writeValue(response.getOutputStream(), error);
            return;
        }
        filterChain.doFilter(request, response);
    }
}

/** Without this, the catch-all handler would turn @PreAuthorize denials into 500s. */
@RestControllerAdvice

public class SecurityErrorAdvice {

  }
}

package com.logplatform.web;

import com.fasterxml.jackson.databind.ObjectMapper;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.boot.autoconfigure.AutoConfiguration;
import org.springframework.boot.autoconfigure.condition.ConditionalOnClass;
import org.springframework.boot.autoconfigure.condition.ConditionalOnMissingBean;
import org.springframework.boot.autoconfigure.condition.ConditionalOnWebApplication;
import org.springframework.boot.web.servlet.FilterRegistrationBean;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.core.Ordered;

@AutoConfiguration
@ConditionalOnWebApplication(type = ConditionalOnWebApplication.Type.SERVLET)
public class WebCommonAutoConfiguration {
  @Bean
  @ConditionalOnMissingBean
  GlobalExceptionHandler globalExceptionHandler() {
    return new GlobalExceptionHandler();
  }

  @Bean
  FilterRegistrationBean<CorrelationIdFilter> correlationIdFilter() {
    FilterRegistrationBean<CorrelationIdFilter> r = new FilterRegistrationBean<>(new CorrelationIdFilter());
    r.setOrder(Ordered.HIGHEST_PRECEDENCE);
    return r;
  }

  @Bean
  FilterRegistrationBean<RequestSizeLimitFilter> requestSizeLimitFilter(
      ObjectMapper objectMapper,
      @Value("${platform.web.max-request-bytes:5242880}") long maxBytes) {
    FilterRegistrationBean<RequestSizeLimitFilter> r =
        new FilterRegistrationBean<>(new RequestSizeLimitFilter(maxBytes, objectMapper));
    r.setOrder(Ordered.HIGHEST_PRECEDENCE + 1);
    return r;
  }

  @Configuration(proxyBeanMethods = false)
  @ConditionalOnClass(name = "org.springframework.security.access.AccessDeniedException")
  static class SecurityAdviceConfiguration {
    @Bean
    SecurityErrorAdvice securityErrorAdvice() {
      return new SecurityErrorAdvice();
    }
  }
}
